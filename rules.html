Правила английского языка

5 групп от базового к продвинутому уровню

1. Базовый уровень (Beginner)

  • To be: am / is / are — I am, he is, they are.
  • Present Simple: I work / He works — привычки, факты.
  • Артикли: a/an (неопределённый), the (определённый), нулевой.
  • Множественное число: -s / -es, неправильные (child → children).
  • Предлоги места: in, on, at, under, next to.
  • Вопросы и отрицания: Do/Does, don't/doesn't, Yes/No questions.

2. Элементарный уровень (Elementary)

  • Past Simple: regular (-ed) и irregular — действия в прошлом.
  • Future Simple: will / going to — планы и предсказания.
  • There is / There are: наличие чего-либо.
  • Степени сравнения: bigger, the biggest, more interesting.
  • Модальные глаголы (базовые): can, must, have to, should.
  • Исчисляемые / неисчисляемые: some / any / much / many.

3. Средний уровень (Pre-Intermediate)

  • Present Continuous: I am working — действие сейчас / временные ситуации.
  • Present Perfect: I have done — опыт, результат, for/since.
  • Past Continuous: I was working — процесс в прошлом.
  • Условные 0 и 1: If + Present → Present / will.
  • Герундий и инфинитив: like doing / want to do.
  • Относительные местоимения: who, which, that, where.

4. Средне-продвинутый (Intermediate)

  • Past Perfect: I had done — действие до другого в прошлом.
  • Future Continuous / Perfect: will be doing / will have done.
  • Пассивный залог: is done / was made / has been built.
  • Условные 2 и 3: If + Past → would / If + Past Perfect → would have.
  • Reported Speech: He said that... (сдвиг времён).
  • Фразовые глаголы: look after, give up, take off.

5. Продвинутый уровень (Upper-Intermediate / Advanced)

  • Смешанные условные: If + Past Perfect → would (сейчас).
  • Инверсия: Never have I seen... / Had I known...
  • Модальные с перфектом: must have done, might have been, should have gone.
  • Субъюнктив и wish: I wish I were / If only I had known.
  • Эллипсис и замены: so do I, neither did she, too / either.
  • Сложные относительные конструкции: whose, whom, preposition + which.
