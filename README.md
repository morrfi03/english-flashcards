# English Flashcards

Простой сайт для запоминания английских слов и фраз с помощью карточек.

## Страницы
- **Изучение** (`index.html`) — карточки: неправильные глаголы, слова/фразы, свои слова
- **Правила** (`rules.html`) — 5 групп правил английского языка

Свои слова сохраняются в localStorage браузера.

## Запуск локально
Откройте `index.html` в браузере.
